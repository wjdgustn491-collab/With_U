# WITH_U Carbon Workspace

기업의 지속가능경영 현황, 탄소배출권 관리, 지속가능경영 리포트를 보여주는 정적 웹사이트입니다.

## 파일 구성

- `index.html`: 전체 화면, 예시 데이터, 메뉴 및 리포트 다운로드 기능
- `theme.css`: 화면 디자인과 모바일 반응형 스타일
- `assets/forest.jpg`: 장식용 숲 이미지
- `ASSET-SOURCES.md`: 이미지 출처와 라이선스

## 실행

압축을 푼 다음 `index.html`을 웹브라우저로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## GitHub에 업로드

ZIP 압축을 푼 후 위 파일과 `assets` 폴더를 저장소의 최상위에 업로드합니다. ZIP 파일 자체를 업로드하는 것이 아닙니다.

GitHub Pages로 게시하려면 저장소의 Pages 설정에서 해당 브랜치의 최상위(`/`)를 게시 대상으로 선택합니다.

## 현재 기능과 데이터

- 대시보드, 탄소배출권, 지속가능경영 리포트 화면
- 2026년 1분기·2분기·3분기·연간 보고 기간
- DOC·CSV 다운로드 및 브라우저 인쇄를 통한 PDF 저장
- 1분기·2분기 수치는 미입력, 나머지 화면 수치는 예시 데이터
- 백엔드, 로그인, 데이터베이스 연결은 포함되어 있지 않습니다.

화면 오른쪽 숲 사진은 장식용 이미지이며 WITH_U의 실제 사업장 사진이 아닙니다.

## 녹지 관리자 (2026-09-22)

홈페이지 상단 `관리자 페이지`에서 `admin.html`로 이동합니다. `carbon-method.html`에는 공식·단위·출처·제약과 센서 JSON 형식이 있습니다.

- GPS 위치 입력, 조사 면적 입력 또는 단일 경계점 다각형의 지역 평면 근사 면적 계산
- 토양 온도·수분·EC·pH: 동일 장치 JSON 기록 파일 가져오기, 결측값 및 시뮬레이션 구분
- 여러 수종 그룹의 기준/현재 수량·DBH·수고와 공통/사용자 계수 입력
- 수목 저장량 및 조사 기간 평균 변화량 산출
- SOC·용적밀도·깊이·조립질 질량비 기반 토양 저장량 및 비교조건 확인 후 변화량 산출
- 예시 입력 및 명시적인 브라우저 로컬 저장. 입력값의 서버 전송 없음

현재 관리자 화면은 공개 시연용이며 인증/실시간 API/자동 녹지 분류가 없습니다. 실제 운영 전 관리자 인증과 장치별 접근권한, 센서 수집·저장 확장이 필요합니다. 기존 environment.py는 토양 온도·수분만 저장하므로 EC·pH는 누락값으로 표시됩니다.

계산 엔진: carbon-engine.js. 기존 scratch/biomass_estimator.py의 수목 식과 가정을 이식하되 저장량과 흡수량을 구분했습니다. 수종별 검증 계수 DB는 없으며 기존 공통 계수를 표시합니다. 온습도·EC·pH에 임의 탄소 보정식을 적용하지 않습니다.

검증: `node carbon-engine.test.cjs` (수목/토양 단위, 결측값, 0, 날짜, 경계 교차, 센서 검증).
