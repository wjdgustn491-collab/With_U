# WITH_U 기업 탄소 관리 MVP

기업 회원 계정, 관리자 계정과 기업별 장치 연결을 분리합니다. 기존 수목 탄소 산정식·위성 녹지 경계·GPS 위치·센서 로직을 유지합니다. 토양·녹지 면적 기반 탄소 산정은 추가하지 않습니다.

## 기업 이용

1. 상단 기업 로그인 / 회원가입에서 아이디·비밀번호·기업명·사업장 및 보고 경계를 등록합니다. 기업 비밀번호는 8자 이상입니다.
2. 로그인하면 해당 기업의 서버 자료와 관리자가 연결한 장치만 조회합니다. 기업명·보고 경계는 회원가입 정보로 고정됩니다.
3. 기업 데이터 입력 화면에서 보고 기간, 장치, 배출 자료·크레딧 자료를 설정합니다. 기업·장치·기간 선택 영역은 이 화면에만 표시됩니다.
4. 입력 저장은 현재 탭의 임시 자료를 갱신합니다. 기업 자료 서버 저장으로 기록·보고서를 계정에 영구 저장합니다. 다른 컴퓨터에서는 로그인해 서버 저장본을 사용합니다. 로그아웃하면 현재 탭의 임시 자료를 삭제합니다.
5. 대시보드의 선택 장치 주변 토양 환경에서 연결 장치를 선택할 수 있습니다. 기업 데이터 입력의 장치 선택과 동기화됩니다.
6. 저장 보고서는 생성 당시 원자료를 보관하고 이후 수정하지 않습니다. DOC(Word에서 열 수 있는 HTML), CSV, 인쇄/PDF를 제공합니다.

활동량 산정: 배출량(tCO₂e) = 활동량 × 배출계수(kgCO₂e/활동량 단위) ÷ 1,000. 귀속일로 기간 합계를 산정합니다. 미입력은 0 배출을 의미하지 않습니다. 적용 배출계수·출처·근거는 기업이 입력합니다. 크레딧은 등록부와 일련번호로 입고·소각·이전을 기록하며 중복 입고·과거 잔량 초과를 차단합니다. 자동 크레딧 발행·상계·외부 등록부 검증은 없습니다.

## 관리자 이용

사이트 하단 관리자 로그인에서 기존 등록 계정만 로그인합니다. 관리자 회원가입·역할 승격 기능은 없습니다. 초기 계정은 요청한 admin / 1234이며 데이터베이스에 bcrypt 해시로 저장합니다. 계정은 SQL 실행 시 한 번 생성하며 재실행으로 기존 암호를 변경하지 않습니다.

관리자 화면은 서버에서 확인한 관리자 세션이 있을 때만 열립니다. 기업별 장치 연결에서 회원가입한 기업과 등록 장치를 선택해 연결·해제합니다. 한 장치는 한 기업에만 연결됩니다. 기업은 장치 연결·위치 변경·수목 조사 편집을 할 수 없습니다.

기존 위치 등록·GPS 조회·고해상도 위성영상·주변 OSM 녹지 한 구역 추산·수종 입력·센서 조회 기능은 유지합니다. 실제 현장 조사 여부를 표시한 뒤 선택 기업에 현장 조사 등록 버튼으로 기업 서버에 수목 자료를 등록합니다. 브라우저의 예시 수목 자료는 자동으로 기업에 등록하지 않습니다.

등록 가능한 장치는 기존 WITHU_ALLOWED_DEVICE_IDS 목록이며 미설정 시 pi5-monitor-01입니다. 기존 장치 전송 API와 장치 전송 토큰은 변경하지 않습니다.

## 실제/예시 구분

- 비로그인, 연결 장치가 없는 기업, 장치 미선택: 명시적인 예시 정보.
- 연결 장치 선택: 해당 기업 입력 자료와 해당 장치의 실제 현장 조사 및 hardware 센서 기록.
- 실제 모드의 미입력·미수집·조회 실패는 예시로 대체하지 않습니다. simulation은 실제 관측값에서 제외합니다.
- 센서는 보고 기간에 관계없이 서버의 최신 관측값을 표시하며 새 측정 요청을 보내지 않습니다. 자동 조회는 기존 6시간 주기입니다. EC·pH는 현재 미수집입니다.
- 수목 결과는 조사 기간의 연평균 저장량 변화입니다. 보고 기간 확정 흡수량으로 자동 환산하지 않습니다.

## 서버 설정

기존 SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY를 서버에서만 사용합니다. 회원에게 서비스 키나 관리자 조회 토큰을 입력하도록 요구하지 않습니다. 기존 WITHU_ADMIN_TOKEN 환경 변수는 남겨두어도 기업·관리자 웹 로그인 인증에 사용되지 않습니다.

SQL Editor 적용 순서: sql/company_workspaces.sql, 기존 sql/device_locations.sql, 새 sql/company_accounts.sql. 새 SQL은 기업 회원·8시간 로그인 세션·로그인 시도 제한·기업별 장치 연결 및 관리자 초기 계정을 만듭니다. 기존 기업·센서·위치 자료를 유지합니다. 계정·세션·장치 연결 테이블에는 RLS를 적용하고 익명·일반 로그인 역할의 직접 접근을 금지하며 서비스 역할로만 처리합니다.

암호 인증은 데이터베이스의 pgcrypto crypt/gen_salt bcrypt를 사용합니다. 임의의 로그인 세션은 서버가 생성하고 데이터베이스에는 SHA-256 해시만 저장합니다. 브라우저 쿠키는 HttpOnly, Secure, SameSite=Lax이며 로그인 유지 시간은 8시간입니다. 변경 요청은 사이트 Origin을 검사합니다. 기업 식별자와 장치 권한은 매 요청마다 서버에서 검사하며 다른 기업 자료·전체 기업 목록·관리자 위치 변경을 차단합니다. 요청 본문으로 관리자 역할을 등록할 수 없습니다. IP별 인증 시도는 15분당 20회 제한합니다.

기업 저장은 서버 버전을 비교하여 다른 컴퓨터의 변경을 덮어쓰지 않도록 합니다. 기존 운영자 MVP의 계정 없는 기업 자료는 자동으로 신규 계정에 귀속하지 않습니다. JSON 백업은 로그인한 기업 식별자·기업 정보·관리자 조사 자료가 일치하는 경우만 복원할 수 있습니다. 고객별 암호 재설정·이메일 인증은 이 변경에 포함하지 않습니다.

## 검증

node --test *.test.cjs api/*.test.cjs

기업 소유권, 관리자 역할, 장치 연결 및 해제, 세션 만료, 기존 토큰 거부, CSRF, 로그인 시도 제한 응답, 관리자 등록 금지, 서버 저장 충돌, 기존 수목·녹지·위치·센서 및 단위 검증을 수행합니다. tools/verify_company_workspace.cjs는 로컬 테스트 서버와 별도 Edge 프로필로 회원가입→관리자 연결→기업 조회·저장→기업 전환·관리자 화면 차단과 모바일 화면을 확인하며 운영 DB에 테스트 기업을 생성하지 않습니다.
