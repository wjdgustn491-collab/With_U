METHODOLOGY / v1

무엇을, 어떻게 계산하나요?

기존 프로젝트의 수목 바이오매스 식을 웹 계산기로 옮기고, 두 시점의 저장량 차이로 기간별 변화를 계산합니다. 토양 센서값과 탄소 분석값은 구분합니다.

1. GPS와 녹지 면적

장치 좌표는 위치 정보입니다. 면적은 별도로 조사한 값이나 경계 순서대로 입력한 WGS84 위도·경도 다각형으로 계산합니다.

면적(ha) = 녹지 면적(m²) ÷ 10,000

경계 계산은 평균 위도에서의 지역 평면 투영과 신발끈 공식을 사용한 근사값입니다. 가로·세로 10 km 이내의 단일 경계만 지원합니다. 구멍·건물·도로가 섞인 복합 부지는 GIS에서 녹지만 추출한 면적을 직접 입력하세요. 위성 영상이나 GPS 한 점으로 녹지를 자동 분류하지 않습니다.

2. 수목 저장량 · 기존 계산식

V = π × (DBH / 200)² × H × F
B = V × ρ × BEF × (1 + R)
S = B × CF × (44 / 12) × N ÷ 1,000

DBH는 cm, 수고 H는 m, 목재 기본밀도 ρ는 kg/m³, N은 그룹 수목 수량입니다. V는 줄기 부피(m³), B는 건조 바이오매스(kg), S는 그룹의 CO₂ 상당 저장량(tCO₂)입니다.

프로젝트 KIM-YU-HYUN / scratch/biomass_estimator.py에서 확인한 기본값: F = 0.45, ρ = 500, BEF = 1.3, R = 0.25, CF = 0.5. 이 값은 기존 코드의 공통 가정이며 모든 수종에 검증된 계수라는 의미가 아닙니다. 수종명만으로 계수를 추정하거나 자동 교체하지 않습니다.

수종별 조사 자료로 계수를 수정할 수 있습니다. 두 시점에 같은 계수를 적용합니다. 이식·벌채·고사, 조사 표본과 전체 수량의 차이를 검토해야 합니다. 수량 기반 계산이므로 결과에 면적을 다시 곱하지 않습니다.

3. 토양 유기탄소 저장량

C = SOC × BD × D × (1 − G/100) × 0.1
S = C × A × (44 / 12)

SOC: g C/kg 세토, BD: 전체 건조토양 용적밀도(g/cm³), D: 토층 두께(cm), G: 2 mm 이상 조립질 질량비(%), A: 면적(ha). C는 tC/ha, S는 해당 녹지의 tCO₂ 상당 저장량입니다.

0.1은 단위 변환값입니다. 예를 들어 SOC 20, BD 1.3, 깊이 30 cm, 조립질 0%이면 78 tC/ha입니다. 이 값은 현재 저장량이며 연간 흡수량이 아닙니다.

한 토층의 대표 분석값을 사용하는 단순 계산입니다. 세토 기준 용적밀도에 조립질 보정을 중복 적용하면 안 됩니다. 서로 다른 토양은 구획별로 조사해야 하며, 압밀 등으로 토양 질량이 달라졌다면 등가 토양 질량 비교를 먼저 검토하세요. 토양 분석값이 없으면 결과를 임의 생성하지 않습니다.

4. 기간별 저장량 변화

기간 변화량 = S현재 − S기준
연평균 변화량 = (S현재 − S기준) ÷ 경과 연수
경과 연수 = 경과 일수 ÷ 365.2425

양수는 증가, 음수는 감소입니다. 같은 경계와 조사 조건으로 비교한 수목·토양 변화량만 합산합니다. 누락값을 0으로 처리하지 않습니다. 연평균값을 월별 실측 흡수량으로 나누지 않으며, 낙엽·고사유기물·비CO₂ 온실가스와 관리활동 배출 등은 포함하지 않습니다.

이 결과는 생물물리적 저장량 변화의 추정치입니다. 대기에서 새로 흡수한 양이라는 주장을 하려면 외부 유기물·이식·반출 등의 영향을 검토해야 합니다. 크레딧 발행이나 기업 배출 상계에 자동 적용하지 않습니다.

방법론 근거: IPCC 2006, Volume 4, Chapter 2의 저장량 변화 접근과 토양 저장량 단위 구조를 참고했습니다. 기존 프로젝트의 개별 기본계수까지 IPCC가 검증했다는 의미는 아닙니다.

5. 센서 데이터 연결 범위

현재 프로젝트의 carbon_monitor/environment.py는 토양 온도·수분을 기록합니다. reference/pi-original/soil_test.py에는 EC·pH 해석 코드가 있지만 운영 저장 구조에는 아직 포함되어 있지 않습니다. 따라서 이 화면은 센서 JSON 파일을 읽어 확인하는 방식이며 자동 수집을 가장하지 않습니다.

{
  "device_id": "RPI-01",
  "timestamp": "2026-09-21T03:00:00Z",
  "source": "hardware",
  "soil_temperature": 21.8,
  "soil_moisture": 47.1,
  "soil_ec": null,
  "soil_ph": null
}

온도 °C, 수분 %, EC µS/cm, pH 0~14. 위 내용은 형식 예시입니다. 기록 1건 또는 동일 장치 기록 배열을 지원하며 배열에서는 최신 날짜를 선택합니다. 누락 항목은 미측정으로 남깁니다. 운영 연결에는 EC·pH 저장 확장, 인증된 조회 API, 장치별 접근 권한과 관리자 로그인이 추가로 필요합니다.

온습도·EC·pH에서 SOC 또는 탄소흡수량으로 바로 환산하는 공식을 넣지 않았습니다. 해당 현장 SOC 시료로 학습·검증한 모델이 확보되면 별도의 예측 경로로 확장할 수 있습니다.
