# WITH_U Carbon Workspace

기업의 지속가능경영 현황, 탄소배출권 관리, 지속가능경영 리포트를 보여주는 정적 웹사이트입니다.

## 파일 구성

- `index.html`: 전체 화면, 예시 데이터, 메뉴 및 리포트 다운로드 기능
- `theme.css`: 화면 디자인과 모바일 반응형 스타일
- `assets/forest.jpg`: 장식용 숲 이미지
- `ASSET-SOURCES.md`: 이미지 출처와 라이선스

## 실행

압축을 푼 다음 `index.html`을 웹브라우저로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## GitHub에 업로드

ZIP 압축을 푼 후 위 파일과 `assets` 폴더를 저장소의 최상위에 업로드합니다. ZIP 파일 자체를 업로드하는 것이 아닙니다.

GitHub Pages로 게시하려면 저장소의 Pages 설정에서 해당 브랜치의 최상위(`/`)를 게시 대상으로 선택합니다.

## 현재 기능과 데이터

- 대시보드, 탄소배출권, 지속가능경영 리포트 화면
- 2026년 1분기·2분기·3분기·연간 보고 기간
- DOC·CSV 다운로드 및 브라우저 인쇄를 통한 PDF 저장
- 1분기·2분기 수치는 미입력, 나머지 화면 수치는 예시 데이터
- 백엔드, 로그인, 데이터베이스 연결은 포함되어 있지 않습니다.

화면 오른쪽 숲 사진은 장식용 이미지이며 WITH_U의 실제 사업장 사진이 아닙니다.
